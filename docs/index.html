Lyra Documentation

Lyra is a friendly, slightly futuristic Discord bot built to feel warm, helpful, and a little bit robotic.

Use this documentation to understand the bot's setup, feature toggles, database design, and project structure.

Quick start

  1. Install dependencies with pip install -r requirements.txt
  2. Copy .env.example to .env and set your Discord token
  3. Run python -m lyra.main

Features

  • Guild-level feature toggles
  • Moderation and logging support
  • Leveling, reminders, and mini-games
  • Blue-themed embeds and consistent bot UX
