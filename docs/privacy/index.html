Privacy Policy

Lyra may store limited Discord data needed for server features, such as guild IDs, user IDs, feature settings, and moderation records.

This data is used for moderation, logging, leveling, and bot configuration only.

Lyra does not sell personal data and does not use it for advertising or unrelated analytics.

Data may be stored in SQLite or a configured database path for operational needs.

Server admins should review all enabled features and configure permissions appropriately.
